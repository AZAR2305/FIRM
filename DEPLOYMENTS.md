# Deployments: Monad Testnet (chain 10143)

**Not deployed yet.** FIRM has not been deployed to the public Monad Testnet from this repository: that needs a funded
deployer key (about 2 MON from <https://faucet.monad.xyz>). This file is regenerated by
`contracts/script/Redeploy.sh` (through `scripts/build-deployments.mjs`) from `deployments/10143.json`, and will then list
every contract address, deployment transaction hash, block and verification status, plus the seeded pools.

```bash
cast wallet import firm-deployer --interactive
cd contracts && DEPLOYER_ACCOUNT=firm-deployer VERIFY=1 ./script/Redeploy.sh
```
